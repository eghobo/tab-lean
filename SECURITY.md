# Security

TabLean does not use a server and does not make network requests. Its permissions should remain limited to the Chrome features required for tab management, local settings, and background checks.

If you find a security or privacy problem, please avoid posting private user information in a public issue. Open an issue with a general description and ask for a private contact method if sensitive details are needed.

Security fixes will be reviewed as a priority. Supported fixes are released through the latest version of TabLean.
