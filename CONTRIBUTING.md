# Contributing to TabLean

Bug reports and focused improvements are welcome.

Before opening a change, please check that it fits TabLean's purpose: reducing Chrome memory use without closing tabs or removing tab groups.

## Making a change

1. Create a branch from `main`.
2. Keep the extension free of remote code and unnecessary permissions.
3. Add or update tests when behavior changes.
4. Run `npm test`.
5. Test the unpacked extension in Chrome.
6. Open a pull request that explains what changed and how it was tested.

Please do not include analytics, advertising, trackers, or external services.
